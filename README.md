&#x20;**Basic Network Sniffer**



A Python-based network sniffer that captures and analyzes network packets using Scapy.



**Features**

\- Capture network packets.

\- Filter TCP, UDP, and ICMP traffic.

\- Display source and destination IP addresses.

\- Show packet sizes and protocol information.

\- Generate a capture summary.

\- Save packet logs locally.



**Technologies**

\- Python

\- Scapy





&#x20;**Installation**



```bash

pip install -r requirements.txt

```



**Usage**



```bash

python src/sniffer.py

```



Select a protocol filter and view the captured packets.
